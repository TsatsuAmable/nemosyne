Quick Start

Define Your First Artefact

Create interactive VR objects with declarative syntax. Bind data, define interactions, and render in minutes.

import { World, Dataset, ConstraintEngine } from 'nemosyne';

// Bootstrap the WebXR world
const world = new World();
await world.start();

// Load a typed dataset
const dataset = Dataset.fromJSON({
  columns: [
    { name: 'item', type: 'string' },
    { name: 'value', type: 'number' }
  ],
  rows: [['A', 12], ['B', 34], ['C', 56]]
});

// Draco chooses layout, geometry, and interaction
world.loadDataset(dataset);
