Quick Start

Explore Your First Dataset

The runtime ships with ten sample datasets. Load one, and the Draco engine will choose the layout and artefacts for you.

import { World } from './src/vr/World.ts';
import { allSampleDatasets } from './src/data/SampleDatasets.ts';

// Bootstrap the three.js/WebXR world
const world = new World();
world.start();

// Load any built-in dataset (HIERARCHY, GRAPH, TIME_SERIES, TABULAR, ...)
world.loadDataset(allSampleDatasets[0]);

// Switch datasets, filter, aggregate, or undo with gestures/wheel menu
// world.loadDataset(allSampleDatasets.find(d => d.key === 'fraud-graph'));

Applications

Transform Your Data

These scenarios are reproducible today with the built-in sample datasets, gesture operations, and live connectors.

🏭 Factory Floor Monitoring

Load the IoT Sensor Stream, connect to the dev-server /__demo-stream, and watch temperature and vibration tokens update in the time ribbon. Time-slice the stream with the wheel menu or sliceDown gesture and pulse magenta halos on anomalous readings.

🔍 Fraud Investigation

Load the Fraud Transaction Graph. Anomaly detection on amount lifts suspicious transactions as glowing orbs. Use pinchTogether or the wheel menu to filter out non-fraud nodes and focus on the fraud chain.

📈 Sales Performance Review

Load the Sales Performance Table. The Draco engine attaches a chart plane automatically. Sort by revenue with sliceUp, aggregate by region, and export the analysis story from the wheel menu.

🏢 Organizational Cost Audit

Load the Organization Chart. Walk the radial tree, aggregate by level, then use the scoopUp gesture to open the statistical lens and see the correlation between employees and budget.

📉 Market Session Replay

Load the Financial Candle Series. Scrub through the OHLCV ribbon with the time-slice operation to replay a trading session and spot volatility clusters in 3D space.

🌍 Geospatial Benchmark

Load Global Cities. Fly over room-scale lat/lon bars sized by population and coloured by GDP, then filter to the largest metros or aggregate by region.
