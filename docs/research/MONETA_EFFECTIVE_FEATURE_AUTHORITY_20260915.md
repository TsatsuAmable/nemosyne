# Moneta effective-feature authority: adversarial design note

**Date:** 2026-09-15  
**Status:** research decision / implementation input, not promotion policy

## Finding

The current Rust `DatasetStructureProfile.dimensionality.effective_dimensions` is not an effective-rank or intrinsic-dimensionality estimator. In `wasm/src/data/profile.rs` it is exactly:

```rust
effective_dimensions: column_count.saturating_sub(constant_columns)
```

The same profile separately reports `redundant_columns`, but redundancy does not affect `effective_dimensions`; moreover `redundant_columns` itself is only `0` or `1`, derived from whether any pairwise correlation exceeds 0.95. The TypeScript evidence adapter transports this field without recomputation, correctly preserving Rust authority but also preserving the narrower semantics of the Rust quantity.

Therefore the field must not be used to relax the conservative ambient `p >= n` admission boundary or populate RFC 0006 `EffectiveFeatureAuthorityReferenceV1` as if it established effective dimensionality.

## Adversarial counterexamples

1. **Exact duplicate columns:** 100 numeric columns generated from one nonconstant variable. Current `effective_dimensions = 100`; algebraic rank is 1.
2. **Linear dependence without pairwise near-duplication:** columns `x`, `y`, `x+y`. Current value is 3 although the numeric matrix rank is at most 2.
3. **Noisy low-rank factor model:** many columns generated by a few latent factors plus noise. Algebraic rank can be full while statistical effective rank is much smaller and depends on spectrum/noise/sample size.
4. **Mixed measurement scales:** nominal/ordinal/compositional columns make a single covariance-rank calculation semantically invalid unless a protocol first defines lawful encoding/geometry.
5. **Compositional closure:** a D-part composition lies on a constrained simplex and carries relative information; raw covariance rank or `D-1` alone does not certify a particular inferential procedure.

These cases falsify the hypothesis that one dataset-wide integer can safely stand for all meanings of "effective features".

## Research constraint

Effective rank is procedure-specific, not a synonym for nonconstant-column count. Covariance literature commonly uses quantities such as `tr(Sigma) / ||Sigma||op` to control covariance-estimation error, under explicit distributional assumptions. Recent AISTATS 2026 rank-adaptive matrix inference likewise shows that an optimal effective rank depends on sample size, noise and the estimation problem. These results support using effective dimension only inside a declared analytical protocol; they do not justify a universal Moneta replacement for `p`.

## Required authority object

RFC 0006 should be satisfied by a Rust/WASM-produced **effective-feature authority artifact**, not by the current structure-profile field. Minimum content:

- dataset fingerprint and immutable ordered source-feature identities;
- measurement-scale classification and admissible preprocessing/geometry;
- target claim/procedure for which dimensionality is being assessed;
- estimator ID + version and assumptions;
- ambient feature count and effective-complexity result;
- uncertainty / stability information where the estimator is sample-dependent;
- perturbation/resampling protocol identity where applicable;
- refusal reasons when assumptions are unsupported;
- kernel version, configuration digest and artifact digest.

The artifact should be candidate/claim bound where feature use differs by representation. A dataset-global authority may be reused only when the exact feature set, geometry and target claim are identical.

## Semantics

Until such an artifact exists:

- `effective_dimensions` remains descriptive schema evidence only;
- high-dimensional admission continues to use conservative ambient feature count;
- no TypeScript fallback may derive effective dimensionality;
- no universal effective-rank threshold is introduced;
- inability to justify the estimator produces scientific `ABSTAIN`, not a heuristic promotion.

## Proposed implementation sequence

1. Rename or epistemically narrow the transported current field to make misuse difficult while retaining compatibility.
2. Add exact-generative Rust tests for duplicate, linear-dependent, low-rank-plus-noise, mixed-scale and compositional controls.
3. Introduce a versioned Rust `EffectiveFeatureAuthorityArtifactV1` distinct from `DatasetStructureProfile`.
4. Implement at least two deliberately distinct estimator protocols rather than pretending one is universal: exact/numerical matrix-rank diagnostics for lawful numeric controls, and a covariance-spectrum effective-complexity protocol with explicit assumptions.
5. Perturb/bootstrap the sample-dependent protocol and report the distribution/stability of the result rather than only a point estimate.
6. Bind the resulting artifact into RFC 0006 certificate verification.
7. Only then research a governing policy for whether a specific claim may substitute certified effective complexity for ambient `p`.

## Claim-bound evidence rule

The effective-feature artifact is evidence, not its own acceptance policy. Certificate verification proves authenticity/context binding. A separate protocol-owned governing criterion decides whether that artifact is admissible for the particular scientific claim. Candidates cannot supply either authority.

## Research leads

- Koltchinskii & Lounici (2017), *Bernoulli*, covariance-operator concentration in terms of effective rank. DOI 10.3150/15-BEJ730.
- Zheng, Jedra & Proutiere (AISTATS 2026), *Near-optimal Rank Adaptive Inference of High Dimensional Matrices*: effective-rank choice trades estimation precision against approximation error and depends on sample size/noise.
- Štefelová, Palarea-Albaladejo & Martín-Fernández (2026), *Statistical Methods in Medical Research*: compositional inference is built on relative/logratio information and high-dimensional compositions introduce additional inferential/computational constraints.

## Finding / hypothesis / speculation

**Finding:** the current `effective_dimensions` name overstates what is computed and cannot safely authorize high-dimensional promotion.

**Hypothesis:** a claim-bound Rust/WASM artifact with explicit estimator semantics and perturbation stability can provide a lawful future route to less conservative high-dimensional admission.

**Speculation:** Full Moneta will need several effective-complexity notions selected by measurement semantics and target claim, not one canonical intrinsic dimension.
