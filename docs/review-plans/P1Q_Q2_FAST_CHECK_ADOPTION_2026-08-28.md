## Decision being implemented

The Q2 pilot classified `fast-check` as **ADOPT WITH SCOPED PROMOTION** for bounded, high-authority TypeScript properties. This tranche converts that pilot decision into ordinary repository wiring without creating a separate property-testing gate.

Adopted scope:

- exact direct dev dependency: `fast-check@4.9.0`;
- lockfile-resolved transitive dependency: `pure-rand@8.4.2`;
- five canonical dataset-identity properties in the existing fast Node lane;
- 250 generated cases per property with fixed replay seeds;
- known expensive threshold behaviour remains covered by the deterministic 50,001-row regression from #496 rather than randomized generation.

## Hosted lockfile generation


1. add `fast-check: 4.9.0` to root `devDependencies`;
2. add the `node_modules/fast-check` lock entry;

## Adopted properties

`tests/q2-dataset-identity-properties.test.ts` retains the five useful pilot invariants:

1. undeclared row/presentation fields do not alter scientific identity;
2. row lineage (`rowIds`) and root presentation metadata do not alter scientific identity;
3. JSON serialize/parse roundtrip preserves canonical scientific identity;
4. graph endpoint JSON type remains scientifically visible (`0` is not `"0"`);
5. missing declared values and explicit `null` converge on the same canonical projection and digest.

The properties use seeds `20260829` through `20260833` and 250 runs each. When a future generated input exposes a real defect, its shrunk counterexample must be retained as a deterministic regression rather than relying only on rediscovery by generation.

## Boundary

This adoption does not make property testing universal. Use `fast-check` where a stable invariant and bounded generator domain exist and where shrinking improves diagnosis. Deterministic examples remain the right tool for fixed regressions, expensive scale boundaries and cases where generated input adds noise rather than signal.

The next Q2 experiment remains a bounded Rust `proptest` pilot against Rust's authoritative canonical fingerprint implementation and shared golden contracts.
