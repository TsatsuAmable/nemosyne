## 4. "No structure detected" vs "insufficient information"

The exit criterion at `docs/ROADMAP.md:168` requires that these remain distinguishable. They are **not** distinguishable along the analytical-evidence path. Four exact collapse points, and one place where the distinction does survive.

### 4.1 Where it survives

**(a) Rust `EvidenceClaim<T>` carries the distinction in types.** `AssumptionStatus::{Satisfied, Violated, Unchecked, NotTestableFromData}` (`wasm/src/data/evidence.rs:8-13`) plus `EvidenceClaim::has_unresolved_assumptions` (`:257-264`); `SampleSupport` with `rows_used` / `rows_excluded` / `policy` / `exclusion_reasons` (`:43-50`); `ApplicabilityStatus::{Applicable, RequiresTransformation, NotApplicable}` (`wasm/src/data/measurement.rs:68-72`); `AdmissionStatus::{Admitted, Rejected}` (`:197-200`).

**(b) It is transported and asserted — but only for the statistics families.** `tests/tec1-statistics-evidence-receipts.test.ts:64` asserts `receipt.assumptions.some((item) => item.status === 'notTestableFromData')` and `:67` asserts `authority.resolve('missing-receipt')` returns `null` (a resolver-level "not there" distinct from "there but empty"). `tests/tec1-statistics-evidence-receipts.test.ts:43` asserts `measurementContext` is exactly `{ status: 'NOT_ESTABLISHED' }`, i.e. the distinction is preserved by *honest absence*.

**(c) The Moneta decision layer separates structural failure from scientific abstention.** `RepresentationDecisionStatus` has five values (`src/moneta/representation/DecisionPolicy.ts:3-8`). `INFEASIBLE` = "No representation candidate satisfies the hard constraints" (`:56-64`); `UNDERDETERMINED` = "below minimum utility" / "effectively tied" (`:69-77`, `:90-98`); `ABSTAIN` = "Current evidence and authority are insufficient to promote a representation in the p >= n regime" (`src/moneta/representation/MonetaHypothesisEngine.ts:341`). This separation is asserted on the production path at `tests/moneta-stability-certificate.test.ts:294-315` ("keeps structural failure INFEASIBLE rather than rewriting it as scientific abstention"), `tests/actionable-nil-ambiguity.test.ts:17-51`, and `tests/moneta-decision-policy.test.ts:19-33`. Note this is a *synthesis/authority* distinction, not an *analytical structure* distinction.

### 4.2 Where it collapses

**Collapse 1 — `src/moneta/representation/DatasetEvidenceSignature.ts:281-295`.** When no graph/hierarchy/temporal/spatial evidence item exists, the code writes:

- source **`'derived'`**, `method: 'structure-profile/topology-absence'`, note "No structured topology profile was emitted; canonical structure profile classifies the dataset as TABULAR". **(Resolved 2026-09-26 — the absence branch now records source `unknown`, matching the hasCycles sibling, with an honest note; the TABULAR compatibility value and its decision treatment are unchanged. See the topology-absence epistemic honesty closure record in `docs/audits/TEC2_HEURISTIC_TERMINOLOGY_INVENTORY_2026-09-21.md`. The underlying transport conflation in Collapse 3 is untouched and remains TEC1/TEC3-relevant.)**

`inferTopology` (`:101-112`) returns `'TABULAR'` positively. Compare `:311-317`, where the directly analogous absence of cycle analysis is written with source **`'unknown'`** and the note "Rust graph profile did not include cycle analysis". So the same class of absence — "we did not measure this" — is recorded as `derived` (an established classification) in one place and `unknown` in another.

**Collapse 2 — `wasm/src/lib.rs:813-826` (`spectral_facts_json`).** Both the invalid-domain case (requested time column absent) and the insufficient-information case (irregular or gapped sampling, `wasm/src/data/spectral.rs:50-51`) produce the literal JSON string `null`, `parameters: serde_json::Value::Null`, and the same `provenance::record("spectral_facts", …)` call. `provenance::record_refusal` is **not** called here — unlike `lib.rs:1039` (mapper graph), `:1096` (persistence intervals) and `:1152` (Betti-0 curve). `tests/uxr3-spectral-transfer-wasm.test.ts:114` and `:134` assert the identical observable `toBeNull()` for the two cases.

**Collapse 3 — `wasm/src/data/profile.rs`.** `Option<…>` conflates three distinct states:
- not applicable — `:1045-1047` returns `(None, None)` for temporal and spectral when there is no temporal stats entry, i.e. the dataset is not a time series;
- insufficient information — the same `None` when `compute_spectral_facts` fails closed on a gap (asserted at `profile.rs:1389-1392`, "missing sample creates a gap; FFT must fail closed");
- no graph declared — `:726-729` combined with `analyze_graph`'s `if edges.is_empty() { return None }` (`:594`);
- hierarchy is unconditionally `None` (`:733`), with the comment at `:730-732` stating hierarchy evidence is intentionally absent.

The TS adapter then simply **omits the evidence item** for each absent family: `src/data/evidence/StructureProfileEvidenceAdapter.ts:254` (`temporal`), `:285` (`spectral`), `:328` (`graph`), `:347` (`hierarchy`), `:364` (`spatial`). Nothing in the emitted `DatasetEvidence` envelope records *why* the item is missing. That omission is what Collapse 1 then reinterprets as `'derived'`. Note also that every structural item is minted with `uncertainty: { kind: 'none' }` (`:65-66`) for all items uniformly.

**Collapse 4 — `wasm/src/data/statistics_evidence.rs:28-31`.** Every receipt is minted with `EvidenceMeasurementContextV1::NotEstablished`, and `geometry` / `uncertainty` / `stability` are `None` and `sensitivity` empty for all four statistics families (`:73-77`, `:91-104`, `:118-123`, `:143-149`). The `Established` variant that would carry `MeasurementModelRecord`, semantic admission policy and `AnalyticalAdmission` is constructed in exactly one place: a Rust unit test (`wasm/src/data/evidence.rs:379-388`). The strongest available signal — "this column is an identifier / ordinal / circular / compositional, therefore the metric is not applicable" — never crosses the WASM boundary.

### 4.3 Net statement

- (i) **Represented in Rust types:** yes — `AssumptionStatus`, `SupportPolicy`/`SampleSupport`, `ApplicabilityStatus`, `AdmissionStatus`, and the five-value `RepresentationDecisionStatus`.
- (ii) **Transported:** partially. The statistics receipt bundle carries `assumptions` and `sampleSupport` and honestly reports `NOT_ESTABLISHED` for measurement context (`wasm/src/data/statistics_evidence.rs:28-31`). The structure-profile path (`StructureProfileEvidenceAdapter.ts`) carries neither assumptions nor support, and drops absent families entirely.
