# Learned Fitness Runtime Adoption

This workstream intentionally stops one step before changing the default Moneta runtime. The new adapter can only re-rank already-feasible candidates with an exact registry-active artifact that still passes the declared promotion policy.

Bootstrap remains authoritative for candidate generation, hard constraints, and raw feature computation. Learned execution must therefore be explicitly enabled in a later composition-root change and pinned by study/runtime configuration to the exact artifact hash.
